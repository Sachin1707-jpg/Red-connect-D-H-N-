# 📜 Changelog - RedConnect

All notable changes to the RedConnect project are documented in this file using [Semantic Versioning (SemVer)](https://semver.org/).

---

## [1.0.0] - 2026-07-22

### 🎉 Initial Release & Complete Documentation Foundation

#### 📄 Documentation Suite Added (`/docs`)
- **README.md**: GitHub project introduction, tech stack details, installation commands, and build scripts.
- **PRD.md**: Detailed Product Requirement Document containing 30+ granular user stories across Donors, Hospitals, NGOs, and Visitors.
- **PROJECT_STRUCTURE.md**: High-level repository structural map and documentation catalog.
- **SYSTEM_ARCHITECTURE.md**: System flow, React/Redux architecture diagrams, and routing layout.
- **FRONTEND_ARCHITECTURE.md**: Layered frontend design, hooks abstractions, and service API client architecture.
- **UI_UX_GUIDELINES.md**: Color tokens (`Crimson Red`, `Slate Dark`), typography scales, spacing grid, and UI states.
- **DESIGN_SYSTEM.md**: Core component specifications including props, variants, and code examples.
- **COMPONENT_DOCUMENTATION.md**: Technical specifications for Navbar, Sidebar, Table, Badge, and Toast components.
- **ROUTING.md**: React Router v6 public, private, and role-protected routes mapping.
- **STATE_MANAGEMENT.md**: Redux Toolkit store layout, slice definitions, and state shape specifications.
- **API_INTEGRATION_GUIDE.md**: Complete REST API specifications with request/response payloads and mock handlers.
- **DATA_FLOW.md**: Data sequence flows for emergency request creation, donor pledges, and form validation.
- **MOCK_DATA.md**: Deterministic JSON mock datasets for users, blood requests, hospital inventories, and rewards.
- **FOLDER_STRUCTURE.md**: Comprehensive file tree breakdown of the `src/` directory.
- **FEATURES.md**: Feature matrix categorized by business priority (P0/P1/P2) and dependencies.
- **USER_FLOW.md**: Mermaid workflow diagrams for Visitor, Donor, Hospital, NGO, and Admin roles.
- **PAGES.md**: Component composition and interaction specifications for every application view.
- **COMPONENT_TREE.md**: Full component hierarchy diagram in Mermaid visual format.
- **RESPONSIVE_DESIGN.md**: Breakpoint scale, touch targets, and mobile layout adaptions.
- **ACCESSIBILITY.md**: WCAG 2.1 AA compliance guidelines, ARIA roles, and keyboard navigation.
- **PERFORMANCE.md**: Code splitting benchmarks, React memoization rules, and bundle budgets.
- **SECURITY.md**: JWT handling, XSS prevention, and role-based access control.
- **ANIMATION_GUIDE.md**: CSS tokens, Framer Motion spring physics, and skeleton shimmer keyframes.
- **CODING_STANDARDS.md**: Code conventions, naming standards, and Git commit guidelines.
- **CONTRIBUTING.md**: Open-source contribution workflow and code review checklists.
- **CHANGELOG.md**: Release history notes.
- **TODO.md**: Initial project task tracking list.
- **ROADMAP.md**: Six-phase execution roadmap from initial frontend setup to global production deployment.
